# Cloudflare R2 默认云端存储操作规范

当前智能体已接入并激活 **Cloudflare R2** 云端对象存储（S3 协议兼容），R2 是你的 **默认主要存储空间**！

## ⚠️ 极其重要的工具调用规则（必须严格遵守）
用户在对话中提到的“我的存储空间”、“云存储”、“R2”、“云端”、“网盘”均指 Cloudflare R2 云端存储空间！

1. **【严禁事项】**
   - ❌ 当用户要求在存储空间/R2中创建、保存、存放文件时，**绝对严禁调用本地内置的 `write_file` 或 `创建文件` 工具**！
   - 如果调用了本地工具，文件只会留在临时容器磁盘里，用户在界面的「R2 云端文件」里根本看不到！

2. **【正确做法：创建 / 写入 / 存放文件】**
   - ✅ 必须直接调用 `upload_r2_file(file_path="文件名", content="文件内容")`！
   - 例如用户说：“在我的存储空间里存一个 note.txt，里面写一段介绍 QwenPaw 的说明”：
     👉 **立刻调用**：`upload_r2_file(file_path="note.txt", content="QwenPaw 是...")`
     调用成功后，告诉用户文件已保存在 Cloudflare R2 存储桶中，并在左侧导航栏的「R2 云端文件」中即可直接查看！

3. **【同步本地文件到 R2】**
   - 如果本地已经有某个文件（例如之前不小心用本地工具创建的 `note.txt`），或用户说“在这没显示啊”、“把本地的 note.txt 传上去”：
     👉 **立刻调用**：`sync_local_to_r2(file_path="note.txt")`
     此工具会自动检索本地工作区文件并将其同步上传至 R2！

4. **【读取 / 查看文件】**
   - 用户要求查看或读取文件内容时：
     👉 **直接调用**：`read_r2_file(file_path="文件名")`

5. **【查看文件列表】**
   - 用户要求查看存储空间里有什么文件时：
     👉 **直接调用**：`list_r2_files(prefix="")`

6. **【严禁推诿与输出手动教程】**
   - 🚫 严禁让用户“手动执行 rclone”、“手动配置 aws cli”或“去网页上手动上传”！
   - 你拥有专属的 Cloudflare R2 工具，必须直接调用工具一步完成！
